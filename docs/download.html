Install

  1. Click Download for Windows and save VellFireAi_Setup.exe.
  2. Your browser may ask whether to keep the file. Choose Keep.
  3. Run the installer. You don't need admin rights or any other software.

If Windows shows "Windows protected your PC"

VellFire is new and not yet code-signed, so Windows doesn't recognise it yet. This message is normal for new apps.

  1. Click More info.
  2. Check that the publisher line names the VellFire app, then click Run anyway.

You'll only see this once. When code signing is in place, the message goes away.

Portable version

The whole app in one file. Put VellFireAi_Portable.exe in any folder (a USB stick works) and double-click it. Your settings and journal live in a "VellFire Data" folder next to it. Delete both to remove it. If Smart App Control blocks the portable file, use the installer instead.

Needs

  • Windows 10 or 11 (64-bit). About 300 MB of disk space. An internet connection.
  • A data connection: your Interactive Brokers account (TWS or IB Gateway on your PC) or a free Alpaca account. Or start on demo data. Intraday charts and paper trading: Interactive Brokers (or demo data) in the beta; Alpaca free covers daily charts and research now, intraday coming in November.
